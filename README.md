# Data Quality Lab

Open **INVESTIGATION.ipynb** for the in-class discussion. It contains the scenario, tasks, response spaces and expandable data references.

## Start

1. Clone or download this repository and open its folder in VS Code/Jupyter.
2. Select the Python environment you tested during the pre-lab. If dependencies are needed, use that environment's Python: `python -m pip install -r requirements-notebooks.txt`.
3. Open INVESTIGATION.ipynb and run the supplied setup cells before editing.

Investigate with SQL, Python/Pandas, or both. Results appear in the notebook. The data is synthetic and provided locally so the activity does not require a database account or cloud service.

## Files

- **INVESTIGATION.ipynb** — instructions, investigation and answers.
- **controls.py** and **transform.sql** — supplied files you may modify as directed.
- **pipeline.py** and **notebook_tools.py** — supplied execution/display infrastructure.
- **data/** — delivery files, inventory, independent controls and customer history.

Keep original inputs unchanged. For Questions 1–3, write tests/results in notebook cells and use the supplied files; do not add separate scripts, notebooks or documents. Question 4 may include optional supporting attachments. Generated work/evidence files are allowed and ignored by Git. Follow the notebook and teaching team's submission instructions. AI and documentation are allowed; verify suggestions yourself.
